When you ask an LLM like `llama3.2` a question via `ChatOllama`, it always replies with a standard chat message object containing raw text. But in real applications, you rarely want raw text—you want clean strings, structured dictionaries, or validated Python objects that your code can work with directly.

That is where **Output Parsers** come in. They act as translators between the unstructured text generated by the LLM and the structured data structures your application expects.

Since you are building your foundational understanding step-by-step using `ChatOllama` and avoiding complex piping syntax (LCEL) for now, we will look at how to use these parsers **explicitly and programmatically** by calling their methods directly.

---

## 1. String Output Parser (`StrOutputParser`)

By default, when you invoke `ChatOllama`, you get back an `AIMessage` object containing metadata, token counts, and the text content. The `StrOutputParser` simply extracts just the raw string text from that message.

```python
from langchain_community.chat_models import ChatOllama
from langchain_core.output_parsers import StrOutputParser
from langchain_core.messages import HumanMessage

# 1. Initialize your model
model = ChatOllama(model="llama3.2", temperature=0)

# 2. Initialize the string parser
parser = StrOutputParser()

# 3. Invoke the model directly
messages = [HumanMessage(content="Give me a one-word greeting.")]
response = model.invoke(messages)

# 4. Pass the message object explicitly to the parser
clean_text = parser.parse(response)

print(clean_text)  # Output: Hello (just the string, no AIMessage wrapper)

```
